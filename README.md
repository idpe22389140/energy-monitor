# ⚡ Energy Monitoring System
### Σύστημα Παρακολούθησης Ενεργειακής Κατανάλωσης Εργοστασίου

**Εργαστηριακό Project — Τεχνολογίες Διαδικτύου στην Ψηφιακή Βιομηχανία**  
Πανεπιστήμιο Δυτικής Αττικής | Τμήμα Μηχανικών Βιομηχανικής Σχεδίασης και Παραγωγής

---

## 📋 Περιγραφή Σεναρίου

Ένα βιομηχανικό εργοστάσιο παραγωγής αποτελείται από πολλαπλές **ζώνες** (γραμμές παραγωγής, αποθήκη, γραφεία) και **μηχανήματα** με διαφορετικές ενεργειακές ανάγκες. Στόχος του συστήματος είναι η **συνεχής καταγραφή και παρακολούθηση** της ενεργειακής κατανάλωσης (kWh) ανά μηχάνημα, ώστε η διοίκηση να μπορεί να:

- Εντοπίζει μηχανήματα με υπερβολική κατανάλωση
- Βελτιστοποιεί την ενεργειακή αποδοτικότητα
- Παρακολουθεί τάσεις κατανάλωσης ανά χρονική περίοδο και ζώνη

## 🗄️ Δομή Βάσης Δεδομένων

### Πίνακας `zones` — Ζώνες εργοστασίου
| Πεδίο | Τύπος | Περιγραφή |
|-------|-------|-----------|
| id | INT PK AUTO_INCREMENT | Μοναδικό αναγνωριστικό |
| name | VARCHAR(100) | Όνομα ζώνης |
| description | TEXT | Περιγραφή ζώνης |
| created_at | TIMESTAMP | Ημερομηνία δημιουργίας |

### Πίνακας `machines` — Μηχανήματα
| Πεδίο | Τύπος | Περιγραφή |
|-------|-------|-----------|
| id | INT PK AUTO_INCREMENT | Μοναδικό αναγνωριστικό |
| zone_id | INT FK | Αναφορά στη ζώνη |
| name | VARCHAR(100) | Όνομα μηχανήματος |
| model | VARCHAR(100) | Μοντέλο |
| rated_power_kw | DECIMAL(8,2) | Ονομαστική ισχύς (kW) |
| status | ENUM | active / inactive / maintenance |

### Πίνακας `energy_readings` — Μετρήσεις κατανάλωσης
| Πεδίο | Τύπος | Περιγραφή |
|-------|-------|-----------|
| id | INT PK AUTO_INCREMENT | Μοναδικό αναγνωριστικό |
| machine_id | INT FK | Αναφορά στο μηχάνημα |
| kwh | DECIMAL(10,3) | Κατανάλωση σε kWh |
| recorded_at | DATETIME | Ημερομηνία/ώρα μέτρησης |
| notes | TEXT | Σημειώσεις |

**Σχέσεις:** `zones` ←(1:N)→ `machines` ←(1:N)→ `energy_readings`

## 🚀 Εγκατάσταση & Εκτέλεση

### Βήμα 1 — XAMPP
1. Κατεβάστε και εγκαταστήστε το [XAMPP](https://www.apachefriends.org/)
2. Εκκινήστε **Apache** και **MySQL** από το Control Panel

### Βήμα 2 — Αρχεία εφαρμογής
```
Αντιγράψτε τον φάκελο energy_monitor στο:
  Windows: C:\xampp\htdocs\energy_monitor\
  Linux:   /opt/lampp/htdocs/energy_monitor/
```

### Βήμα 3 — Βάση δεδομένων
1. Ανοίξτε `http://localhost/phpmyadmin`
2. Κλικ **Import** → επιλέξτε `database.sql` → **Go**

### Βήμα 4 — Εκτέλεση
Ανοίξτε: `http://localhost/energy_monitor/`

## 🌐 Δικτυακή Αρχιτεκτονική (Μέρος Β)

Υλοποιήθηκε στο **Cisco Packet Tracer** με τα εξής χαρακτηριστικά:

- **Τοπολογία:** Κυκλική (Ring)
- **Συσκευές:** 5 Routers, 2 Switches, 1 Server-PT, 1 PC
- **Πρωτόκολλο δρομολόγησης:** OSPF (Open Shortest Path First) — Area 0
- **Δοκιμή συνδεσιμότητας:** ping & tracert από PC → Server
- **HTTP πρόσβαση:** Ο PC προσπελαύνει το Energy Monitor μέσω Web Browser
